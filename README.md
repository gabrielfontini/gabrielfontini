# Gabriel Fontini Ferreira

### Electronic Engineering | Embedded Systems | Firmware | Digital Design

Electronic Engineering student at **UTFPR — Federal University of Technology – Paraná**, focused on embedded systems, low-level firmware, digital electronics and hardware–software integration.

I build projects that connect **electronics, C/C++ firmware, microcontrollers, FPGA and Linux**, with growing interest in **TinyML and Edge AI** for intelligent embedded devices.

## Featured Projects

### [C3CAN — ESP32-C3 USB-to-CAN Adapter](https://github.com/gabrielfontini/c3can)

Open-source USB-to-CAN interface based on the ESP32-C3, designed for integration with Linux SocketCAN.

**Stack:** `C` `ESP32-C3` `ESP-IDF` `FreeRTOS` `TWAI` `CAN 2.0` `SLCAN` `SocketCAN` `Linux`

---

### [Nios II Traffic Light Controller](https://github.com/gabrielfontini/nios2-traffic-light-controller)

Embedded traffic-control system combining FPGA logic, a Nios II soft-core processor and embedded firmware.

**Stack:** `C` `VHDL` `FPGA` `Nios II` `Avalon-MM` `UART` `ESP32` `Quartus Prime`

---

### [STM32 Bare-Metal Temperature Controller](https://github.com/gabrielfontini/iogurteira-automatica-stm32-g031)

Temperature-control system implemented on an STM32G031 with low-level peripheral access and a finite-state-machine architecture.

**Stack:** `C` `STM32` `ARM Cortex-M0+` `Bare Metal` `ADC` `RTC` `Timers` `LCD`

---

### [Digital Clock in VHDL](https://github.com/gabrielfontini/relogio-digital-vhdl)

Modular digital clock implemented on FPGA using VHDL.

**Stack:** `VHDL` `FPGA` `Digital Logic` `Quartus Prime`
